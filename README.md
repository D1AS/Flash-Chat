# Flash Chat

## Overview

Flash Chat is an iOS messaging application that enables real-time communication using Firebase Firestore as a cloud-based backend.

## Features

- 📱 Real-time messaging
- 🔐 Firebase user authentication
- ☁️ Cloud message storage

## Technical Specifications

- Language: Swift
- Backend: Firebase Firestore
- Architecture: UIKit
- Dependency Management: Swift Package Manager

## Installation

1. Clone the repository
2. Configure Firebase project
3. Provide your own GoogleService-Info.plist
4. Install dependencies
5. Build and run
